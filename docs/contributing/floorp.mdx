Thank you for your interest in improving Floorp!\
This page outlines the main ways you can contribute to Floorp's growth.

The easiest way to contribute is simply to use Floorp.

## Help Other Users

While we try our best to listen to our users as much as possible, there is a limit to what a small team like ours can oversee.

If you see other Floorp users having trouble and it's something you can solve, please lend them a hand.\
Thank you to everyone who is already helping out!

## Submit an Issue

If you encounter an unreported bug, please report it on GitHub.\
While it may be difficult to reply to everyone, we gratefully review all reports we receive.

For more details, please check the ["Issue Submission Checklist"](/docs/other/issue-checklist).

## Contribute Code

If you have programming knowledge, you can also improve features or fix bugs.

For example, the development of the Floorp browser takes place primarily in the `main` branch of the [Floorp repository](https://github.com/Floorp-Projects/Floorp).\
Please check [`CONTRIBUTING.md`](https://github.com/Floorp-Projects/Floorp/blob/main/.github/CONTRIBUTING.md) for more details.

## Improve Translations

Floorp's localization is made possible by contributors around the world.

### Improve Browser Localization

Please join the [Crowdin project](https://crowdin.com/project/floorp-browser).

If you are looking to improve American English localization, please check [this](https://github.com/Floorp-Projects/f18n-central#improving-the-english-us-localization).

### Improve Floorp Docs Localization

These documents are managed in the [floorp-docs-neo](https://github.com/Floorp-Projects/floorp-docs-neo) repository.

- Non-English language files are located in `i18n/[yourLang]/docusaurus-plugin-content-docs/current`.
- English language files are located in `docs`.

In order for a document to appear on the website, it must be available in English. Adding only non-English documents will not display them on the website.

Please check [this page](/docs/contributing/floorp-docs) for more information.

## Support the Project

Floorp is an open-source web browser driven by the community. Your support is essential for ensuring the project's sustainability and covering costs like server maintenance. If you enjoy using Floorp, please consider supporting the project.

For more details on how you can support us, please visit [this page](/docs/contributing/donate).

## Collaborate with the Project

If you are interested in working together with the Floorp Projects, please contact the [Floorp Team](/docs/values/research).

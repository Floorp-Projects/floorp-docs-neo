Floorp の改善にご興味をお持ちいただきありがとうございます！\
このページでは、Floorp の成長に寄与できる主な方法をご紹介します。

最も簡単な方法は、Floorp をお使いいただくことです。

## 他のユーザーを手助けする

できるだけユーザーの皆様に耳を傾けるべく努力をしていますが、私たちのような小さなチームで見られる範囲には限界があります。

他の Floorp ユーザーが困っていて、それがあなたの力で解決できそうなものなら、ぜひその方を助けてあげてください。\
実際に手助けしていただいている皆様、いつもありがとうございます。

## 問題を報告する

報告されていない不具合に遭遇された場合は、GitHub にお寄せください。\
すべてにお返事するのは難しいかもしれませんが、いただいたご報告はすべてありがたく確認させていただきます。

詳しくは ["Floorp の問題を報告する"](/docs/other/issue-checklist) をご確認ください。

## コードを提供する

プログラミングの知識をお持ちの方は、機能の改善や不具合の修正を行うこともできます。

たとえば、Floorp ブラウザーの開発は主に [Floorp リポジトリ](https://github.com/Floorp-Projects/Floorp) の `main` ブランチで行われています。\
詳しくは [`CONTRIBUTING.md`](https://github.com/Floorp-Projects/Floorp/blob/main/.github/CONTRIBUTING.md) をご確認ください。

## 翻訳を改善する

Floorp のローカライズは、世界中の貢献者によって実現されています。

### ブラウザーの翻訳を改善する

[Crowdin プロジェクト](https://ja.crowdin.com/project/floorp-browser)にご参加ください。

アメリカ英語の改善をお考えの場合は、[こちら](https://github.com/Floorp-Projects/f18n-central#improving-the-english-us-localization)をご確認ください。

### Floorp Docs の翻訳を改善する

このドキュメントは [floorp-docs-neo](https://github.com/Floorp-Projects/floorp-docs-neo) リポジトリで管理されています。

- 英語以外の言語ファイルは `/tree/dev/i18n/[あなたの言語]/docusaurus-plugin-content-docs/current` にあります。
- 英語の言語ファイルは `/tree/dev/docs` にあります。

ドキュメントをウェブサイトに表示させるためには、英語のドキュメントが必要です。英語以外のドキュメントのみを追加しても、ウェブサイトには表示されません。

詳しくは[こちらのページ](/docs/contributing/floorp-docs)をご確認ください。

## プロジェクトを支援する

Floorp は、コミュニティ主導のオープンソースウェブブラウザーです。プロジェクトの持続可能性を担保し、サーバーなどの費用を賄うためには、皆様のご支援が不可欠です。Floorp を気に入っていただけましたら、ぜひご支援のご検討をお願いいたします。

ご支援の方法については、[こちらのページ](/docs/contributing/donate)をご覧ください。

## プロジェクトと連携する

Floorp プロジェクトと一緒に何かを行うことにご興味をお持ちの場合は、[Floorp チーム](/docs/values/research)までご連絡ください。

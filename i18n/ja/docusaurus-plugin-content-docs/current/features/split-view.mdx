### Floorp で強化された分割ビュー

Floorp は Firefox の分割ビュー機能をさらに発展させ、より直感的に分割したり、より多くのタブを同時に分割して表示することができます。

Firefox の分割ビューについて、詳しくは [Mozilla サポート](https://support.mozilla.org/kb/split-view-firefox)をご確認ください。

#### さらに多くのタブを同時に表示する

分割ビュー状態のタブを右クリックすると、さらに区分けを追加したり、分割ビューの並べ方を変更したりできます。

<img src={GridView} width="100%" alt="4 つのタブをグリッド表示している様子"/>

:::tip

バージョン 12.14.2 時点では、最大 4 つのタブを分割できます。

:::

#### タブをドラッグして分割する

**Floorp Hub > タブと外観 > タブをドラッグして分割ビューを作成** を有効にした状態で、タブをウェブページの領域までドラッグすると、分割ビューを開始するためのオーバーレイが表示されます。

上下左右のいずれかでドロップすると、ページはその方向に分割して表示されます。ページの領域の中央に表示されるエリアでドロップすると、そのタブは新しいウィンドウに移動します。

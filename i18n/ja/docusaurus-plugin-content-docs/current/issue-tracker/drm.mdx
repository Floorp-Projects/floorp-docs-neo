### DRM とは

DRM (Digital Rights Management) は著作権保護メカニズムです。\
DRM で保護されたコンテンツを再生しようとすると、ウェブサイトは必要な DRM が利用可能かどうかを確認します。\
ほとんどのブラウザーは、DRM に Google の [Widevine](https://www.widevine.com/) を使用しています。

Floorp では現時点で Widevine の正式対応を提供していません。\
そのため、Floorp では DRM で保護されたビデオや音楽を現時点で正常に再生することができません。

### 現在の対応状況

Floorp Project では、Widevine の正式対応に向けた取り組みを開始しており、Floorp へ Widevine を統合するために必要な要件について Widevine への問い合わせを行っています。

Widevine の統合には、Google との法的・技術的なオンボーディングに加え、製品固有の署名、検証、配布、セキュリティ要件などが必要となる場合があります。これらの要件や承認プロセスは Widevine 側によって管理されるため、現時点では対応時期の見通しや、正式対応が承認されることを保証することはできません。

公開可能な進展が確認でき次第、このページを更新します。

### DRM で保護されたコンテンツを再生する方法

Firefox や Chrome など、必要なライセンスを持っている主要なブラウザーを使用することができます。

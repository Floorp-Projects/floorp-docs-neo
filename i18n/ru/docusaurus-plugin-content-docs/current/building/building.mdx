Сборка Floorp не компилирует Firefox из исходного кода. Система сборки (`feles-build`) загружает готовый Floorp Runtime для вашей платформы, собирает собственные ресурсы Floorp поверх него и запускает результат — поэтому ни GitHub-токен, ни инструменты сборки Mozilla не требуются.

## Общие требования

- [git](https://git-scm.com/downloads)
- [Deno](https://deno.com/) 2.x

## Полезные команды

```bash
deno install --allow-scripts                        # Установить зависимости
deno task feles-build dev                           # Режим разработки с HMR
deno task feles-build stage                         # Продакшн-ресурсы, браузер в режиме разработки
deno task feles-build build --phase before-mach     # Продакшн-ресурсы
deno task feles-build build --phase after-mach      # Внедрение после сборки
deno task test                                      # Юнит-тесты внутри браузера
deno task dev-tool                                  # CLI для инспекции браузера (Marionette)
```

## Требования

### Характеристики компьютера

- Оперативная память: Минимум 4 ГБ, рекомендуется 8 ГБ и более.
- Дисковое пространство: Не менее 10 ГБ свободного места.
- Операционная система: Последняя версия Ubuntu.

### Необходимые инструменты

- [git](https://git-scm.com/download/linux)
- [deno](https://deno.com/)

## Шаги установки

1. Установите Deno:

```bash
curl -fsSL https://deno.land/install.sh | sh
```

2. Клонируйте репозиторий Floorp:

```bash
git clone https://github.com/Floorp-Projects/Floorp
cd Floorp
```

3. Настройте токен GitHub:

GITHUB_TOKEN необходим для загрузки артефактов из GitHub Actions.

Выберите один из следующих способов:

**Вариант 1: использование файла .env (рекомендуется)**

Создайте файл `.env` в корне репозитория и добавьте:

```
GITHUB_TOKEN=your_token_here
```

**Вариант 2: использование переменной окружения**

```bash
export GITHUB_TOKEN=your_token_here
```

**Как создать токен GitHub:**

1. Перейдите на https://github.com/settings/tokens
2. Нажмите «Generate new token (classic)»
3. Выберите область доступа `public_repo` (или `repo` для приватных репозиториев)
4. Скопируйте созданный токен и укажите его одним из способов выше

4. Установите зависимости:

```bash
deno install
```

5. Соберите Floorp:

```bash
deno task feles-build dev
```

Браузер запустится и будет автоматически перезагружаться при изменении исходного кода (с использованием горячей перезагрузки или HMR, если поддерживается), так что вам не потребуется его перезапускать.

Поздравляем! Вы успешно собрали Floorp!

---
title: Сборка Floorp на Windows
---

:::danger
Мы не можем предоставить поддержку в случае сбоя сборки.
Пожалуйста, примите это во внимание, прежде чем приступать к следующим шагам.
:::

## Требования

### Характеристики компьютера

- Оперативная память: минимум 4 ГБ, рекомендуется 8 ГБ и более.
- Дисковое пространство: не менее 40 ГБ свободного места.
- Операционная система: последняя версия Windows.

### Необходимые инструменты

- [git](https://git-scm.com/downloads/win)
- [deno](https://deno.com/)

## Шаги установки

1. Установите Deno:

```bash
irm https://deno.land/install.ps1 | iex
```

2. Установите PowerShell 7 или новее:

```bash
# С помощью Winget (рекомендуется)
winget install --id Microsoft.PowerShell --source winget

# Или скачайте со страницы релизов GitHub:
# https://github.com/PowerShell/PowerShell/releases
```

3. Клонируйте репозиторий Floorp:

```bash
git clone https://github.com/Floorp-Projects/Floorp
cd Floorp
```

4. Настройте GitHub Token:

GITHUB_TOKEN необходим для загрузки артефактов из GitHub Actions.

Выберите один из следующих способов:

**Вариант 1: файл .env (рекомендуется)**
Создайте файл `.env` в корне репозитория и добавьте:

```
GITHUB_TOKEN=your_token_here
```

**Вариант 2: переменная окружения**

```bash
$env:GITHUB_TOKEN="your_token_here"
```

    **Как создать GitHub Token:**

    1. Перейдите на https://github.com/settings/tokens
    2. Нажмите «Generate new token (classic)»
    3. Выберите область `public_repo` (или `repo` для приватных репозиториев)
    4. Скопируйте созданный токен и задайте его, как описано выше

5. Установите зависимости:

```bash
deno install
```

6. Соберите Floorp:

```bash
deno task feles-build dev
```

Браузер запустится и будет автоматически перезагружаться при изменении исходного кода (с использованием горячей перезагрузки или HMR, если она поддерживается), так что перезапускать его не потребуется.

Поздравляем! Вы успешно собрали Floorp!

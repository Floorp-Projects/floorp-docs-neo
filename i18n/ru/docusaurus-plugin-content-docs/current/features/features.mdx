### Об этом документе

Добро пожаловать в документацию поддержки пользователей по функциям Floorp. Здесь описаны функции, характеристики и способы настройки браузера.

Чтобы найти нужную информацию, откройте соответствующий документ в левой боковой панели.

:::info
Этот раздел документации предназначен для поддержки пользователей и не содержит технических деталей, относящихся к разработке.

Примечание: этот документ применим к последней версии Floorp для настольных компьютеров. Он не применим к старым настольным или мобильным версиям.
:::

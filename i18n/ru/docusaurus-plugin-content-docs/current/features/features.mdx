### Об этом документе

Это справочная документация по функциям Floorp для пользователей. Здесь мы описываем функции, спецификации и способы настройки Floorp.

Нужные документы можно открыть в левой боковой панели.

:::info
Этот раздел документации предназначен для поддержки пользователей и не содержит технических деталей, важных для разработки.

Примечание: этот документ относится к последней версии Floorp для компьютеров. Он не относится к более старым версиям для компьютеров и к мобильным версиям.
:::

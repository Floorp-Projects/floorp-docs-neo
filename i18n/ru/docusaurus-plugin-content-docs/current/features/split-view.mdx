### Улучшенный разделённый просмотр во Floorp

Floorp расширяет встроенный разделённый просмотр Firefox, позволяя разделять страницы более интуитивно и одновременно отображать ещё больше вкладок.

Подробнее о встроенном разделённом просмотре Firefox читайте в [поддержке Mozilla](https://support.mozilla.org/kb/split-view-firefox).

#### Одновременное отображение ещё большего числа вкладок

Щелчок правой кнопкой мыши по вкладке, которая уже находится в разделённом просмотре, позволяет добавить дополнительные разделения или изменить расположение разделённых представлений.

<img src={GridView} width="100%" alt="4 вкладки, отображаемые в виде сетки"/>

:::tip

Начиная с версии 12.14.2, можно одновременно разделить до 4 вкладок.

:::

#### Разделение вкладок перетаскиванием

Когда включена настройка **Floorp Hub > Вкладки и внешний вид > Разрешить создание разделённого просмотра перетаскиванием вкладок**, перетаскивание вкладки в область веб-страницы отображает оверлей для запуска разделённого просмотра.

Если отпустить вкладку у верхнего, нижнего, левого или правого края, страница будет разделена в соответствующем направлении. Если отпустить её в центральной области, вкладка будет перемещена в новое окно.

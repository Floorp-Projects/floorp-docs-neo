### Улучшенный разделённый вид в Floorp

Floorp развивает встроенный разделённый вид Firefox, позволяя разделять страницы более интуитивно и отображать ещё больше вкладок одновременно.

Подробнее о встроенном разделённом виде Firefox см. в [поддержке Mozilla](https://support.mozilla.org/kb/split-view-firefox).

#### Ещё больше вкладок одновременно

Щелчок правой кнопкой мыши по вкладке, которая уже находится в разделённом виде, позволяет добавить новые области или изменить раскладку разделённого вида.

<img src={GridView} width="100%" alt="4 вкладки, отображаемые в виде сетки"/>

:::tip

Начиная с версии 12.14.2, можно одновременно разделять до 4 вкладок.

:::

#### Перетаскивание вкладок для разделения

Если включён параметр **Центр Floorp > Вкладки и внешний вид > Разрешить создавать разделённый вид перетаскиванием вкладок**, при перетаскивании вкладки в область веб-страницы появляется оверлей для запуска разделённого вида.

Если отпустить вкладку у верхнего, нижнего, левого или правого края, страница разделится в этом направлении. Если отпустить её в центральной области, вкладка переместится в новое окно.

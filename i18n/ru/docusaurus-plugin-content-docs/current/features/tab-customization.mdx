### Настройка вкладок в Floorp

Floorp предлагает множество параметров для закрепления вкладок, прокрутки, расположения новых вкладок, минимального размера вкладок и закрытия вкладок двойным щелчком.\
Эти параметры рассчитаны на совместную работу с другими настройками панели вкладок.

Изменить эти настройки можно в разделе **Настройки > Вкладки и внешний вид > Вкладки**.

### Настройка поведения вкладок

#### Прокрутка

Настройте, переключаются ли вкладки прокруткой колеса мыши и как именно работает эта прокрутка.

- **Переключение вкладок при прокрутке**

    Если включено, вкладки можно переключать простой прокруткой на панели вкладок.\
    По умолчанию функция отключена, и при переполнении панель вкладок прокручивается по горизонтали.

- **Обратное направление прокрутки вкладок**

    Если включено, направление переключения вкладок прокруткой меняется на обратное.\
    По умолчанию отключено; требует включённого параметра «Переключение вкладок при прокрутке».

- **Циклическая прокрутка вкладок**

    Если включено, прокрутка после последней вкладки возвращается к первой (и наоборот).\
    По умолчанию отключено; требует включённого параметра «Переключение вкладок при прокрутке».

:::tip

Переключать вкладки также можно с помощью [горячих клавиш](/docs/features/shortcuts-and-palette), [жестов мышью](/docs/features/mouse-gestures) и [палитры команд](/docs/features/shortcuts-and-palette).

:::

#### Расположение новых вкладок

Задайте расположение, в котором новые вкладки открываются по умолчанию.

- **Следовать поведению Firefox**

    Расположение новых вкладок меняется в зависимости от того, как вы открываете ссылку, и от ваших текущих действий.\
    Это настройка по умолчанию.

- **Открывать в конце панели вкладок**

    Новые вкладки всегда открываются в самом конце панели вкладок.

- **Открывать рядом с текущей вкладкой**

    Новые вкладки всегда открываются сразу справа от активной вкладки.

#### Другие настройки

Настройте дополнительные параметры: поведение закреплённых вкладок, действие двойного щелчка и размеры.

- **Показывать заголовки закреплённых вкладок**

    Если включено, закреплённые вкладки будут показывать текстовые заголовки рядом со значками, а не только значок.\
    По умолчанию отключено.

- **Закрывать вкладку двойным щелчком**

    Если включено, двойной щелчок по активной вкладке сразу закрывает её.\
    По умолчанию отключено.

- **Минимальная ширина вкладок**

    Задаёт минимальную ширину вкладок в пикселях (px). Это минимальный порог; в зависимости от настроек раскладки вкладки могут быть шире.\
    Значение по умолчанию — `76`.

- **Минимальная высота вкладок**

    Задаёт минимальную высоту вкладок в пикселях (px). Это минимальный порог; в зависимости от настроек раскладки вкладки могут быть выше.\
    Значение по умолчанию — `30`.

### Настройка поведения вкладок и окон

- **Открывать ссылки, запрашивающие новое окно**

    Выберите, открывать ли ссылки, настроенные на открытие в новом окне, в текущем окне, в новом окне или в новой вкладке.

- **Показывать предпросмотр вкладок на панели задач**

    Доступно только в Windows. Если включено, отдельные вкладки отображаются на панели задач.

### Исключения при выгрузке вкладок

Firefox имеет встроенную функцию, которая автоматически выгружает вкладки из памяти при нехватке оперативной памяти, чтобы браузер не падал.\
Floorp позволяет указать сайты, которые не будут выгружаться автоматически.

Шаблоны исключений можно вводить в следующих форматах:

- **`floorp.app`**

    Исключает все URL, содержащие `floorp.app`, из автоматической выгрузки.

- **`*.floorp.app`**

    Исключает поддомены `floorp.app` (например, `docs.floorp.app` или `blog.floorp.app`) из выгрузки. Обратите внимание, что сам основной домен `floorp.app` этим шаблоном не исключается.

- **`https://docs.floorp.app/*`**

    Исключает все страницы внутри `docs.floorp.app` из автоматической выгрузки.

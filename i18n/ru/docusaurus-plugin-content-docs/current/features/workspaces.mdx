### Что такое рабочие пространства?

Рабочие пространства позволяют эффективно группировать вкладки и управлять ими.

Например, если вы создадите рабочее пространство «Покупки», все вкладки внутри него будут принадлежать группе «Покупки».\
Аналогично, если вы создадите другое рабочее пространство «Блог», все вкладки внутри него будут принадлежать группе «Блог».

Одновременно в одном окне может отображаться только одно рабочее пространство.

Благодаря такой группировке вкладок количество видимых вкладок значительно уменьшается, что делает интерфейс чище и повышает эффективность просмотра.\
Вкладки в неактивных рабочих пространствах остаются открытыми в фоне, поэтому введённые вами данные не будут потеряны.

:::note

Начиная с версии 12.14.2, структуры рабочих пространств являются общими в рамках одного профиля, но отдельные вкладки не являются общими.

:::

### Как использовать рабочие пространства

<img src={ToolBarButton} height="350px" alt="Как использовать рабочие пространства" style={{margin: "10px 0"}}/>

Нажатие кнопки на панели инструментов, показанной на изображении, откроет панель управления рабочими пространствами.

По умолчанию автоматически создаётся рабочее пространство с названием «Новое рабочее пространство (0)». Текущее активное рабочее пространство будет выделено.

Вы можете добавить ещё одно рабочее пространство, нажав «Создать новое рабочее пространство...».

#### Управление рабочими пространствами

Чтобы переименовать или настроить рабочее пространство, щёлкните правой кнопкой мыши по нужному рабочему пространству в панели управления и выберите «Управлять рабочим пространством».\
Также можно настроить текущее активное рабочее пространство, нажав значок шестерёнки в правом нижнем углу.

#### Архивирование рабочих пространств

Щёлкните правой кнопкой мыши по рабочему пространству и выберите «Архивировать», чтобы удалить его и его вкладки из основного списка.

Вы можете в любой момент просмотреть ранее архивированные рабочие пространства, нажав значок папки в правом нижнем углу панели управления рабочими пространствами.

### О контейнерах рабочих пространств

Эта функция, появившаяся в [Floorp 11.4.0](https://blog.ablaze.one/3510/2023-09-22/), позволяет заранее назначать контейнеры Firefox Multi-Account Containers конкретному рабочему пространству.

Как описано в разделе «Как использовать рабочие пространства», щёлкните правой кнопкой мыши по нужному рабочему пространству в панели управления и выберите «Управлять рабочим пространством».\
Затем выберите предпочитаемый контейнер в выпадающем меню «Контейнер» внутри панели управления.

Подробнее о контейнерных вкладках читайте в [официальной документации Mozilla](https://support.mozilla.org/kb/containers#firefox).

### Настройка рабочих пространств

Перейдите в **Floorp Hub > Рабочие пространства** (`about:hub#/features/workspaces`), чтобы открыть дополнительные настройки.

- **Закрывать всплывающее окно рабочих пространств при выборе рабочего пространства**

    Включено по умолчанию. Определяет, закрывается ли панель рабочих пространств автоматически после выбора рабочего пространства.

- **Показывать название рабочего пространства рядом со значком**

    Включено по умолчанию. Определяет, отображается ли название рабочего пространства рядом с его кнопкой на панели инструментов.

- **Завершать Floorp при закрытии последней вкладки рабочего пространства**

    Отключено по умолчанию. Определяет, закрывается ли всё окно после закрытия всех вкладок внутри рабочего пространства.

- **Управлять рабочими пространствами в боковой панели Floorp**

    Отключено по умолчанию. Отображает список рабочих пространств непосредственно в [Панельной боковой панели](/docs/features/panel-sidebar) для быстрого переключения. Обратите внимание, что некоторые функции, доступные во всплывающем окне панели инструментов, в этом режиме не поддерживаются.

- **Сбросить рабочие пространства**

    Сбрасывает данные рабочих пространств к состоянию по умолчанию.\
    Все пользовательские рабочие пространства будут удалены, а все существующие вкладки будут переназначены новому рабочему пространству по умолчанию. **Это действие нельзя отменить.**

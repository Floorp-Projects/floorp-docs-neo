## Windows

### Поддерживаемые операционные системы

- Windows 11 64-bit
- Windows 10 64-bit

### Системные требования

- Процессор с поддержкой SSE4.1
- 2 ГБ ОЗУ
- 200 МБ свободного места

### Установка

- **Установщик и Portable-версия**

  1. Откройте [официальный сайт](https://floorp.app/download) и скачайте установщик Windows или Portable-версию.
  2. Portable-версию можно использовать сразу. При использовании установщика следуйте инструкциям на экране.

:::tip[Различия]

- **Онлайн-установщик** устанавливает Floorp из интернета.
- **Офлайн-установщик** устанавливает Floorp без подключения к интернету.
- **Portable-версия** не требует установки, но может иметь некоторые ограничения.

:::

- **Winget**

  ```shell
  winget install Ablaze.Floorp
  ```
  Предоставлено **[@Hibi_10000](https://github.com/Hibi-10000)**.
- **Scoop**

  ```shell
  scoop bucket add extras
  scoop install extras/floorp
  ```

  Предоставлено **[@SegoCode](https://github.com/SegoCode)**.

## Mac

### Поддерживаемые операционные системы
macOS Catalina 10.15 - macOS Sequoia 15

### Системные требования

- Mac с процессором Intel x86 или Apple Silicon
- 512 МБ ОЗУ
- 200 МБ свободного места

### Установка

1. Откройте [официальный сайт](https://floorp.app/download) и скачайте `floorp-macOS-universal.dmg`.
2. Откройте загруженный файл и перетащите `Floorp.app` в папку `Applications`.

  Убедившись, что Floorp появился в папке «Программы» или Launchpad, вы можете извлечь образ установщика Floorp.

## GNU/Linux

### Программные требования

- **Для работы Floorp требуются следующие пакеты**:

    - GTK+ 3.14 или новее
    - X.org 1.0 или новее (рекомендуется 1.7 или новее)
    - libstdc++ 4.8.1 или новее
    - glibc 2.17 или новее

- **Для наилучшей функциональности убедитесь, что установлены следующие пакеты**:

    - NetworkManager 0.7 или новее
    - DBus 1.0 или новее
    - GNOME 2.16 или новее
    - PulseAudio

### Установка

Поддерживаемые пакетные менеджеры:
```text
1. PPA (Ubuntu, Linux Mint и т.д.)            "https://ppa.floorp.app"

2. Flatpak (все дистрибутивы Linux)           "https://flathub.org/apps/one.ablaze.floorp"

3. tarball (все дистрибутивы Linux)           "https://GitHub.com/Floorp-Projects/Floorp/releases/latest"

4. AUR bin (дистрибутивы на базе Arch)        "https://aur.archlinux.org/packages/floorp-bin/" **Неофициально**

5. AUR (дистрибутивы на базе Arch)            "https://aur.archlinux.org/packages/floorp/" **Неофициально**

6. SBo bin (дистрибутивы на базе Slackware)   "https://slackbuilds.org/repository/15.0/network/floorp-bin/" **Неофициально**
```

Версия Flatpak может иметь собственные ограничения из-за «песочницы». [Подробнее](/docs/issue-tracker/flatpak)

## Загрузка из GitHub Releases

Вы можете скачать выпуски Floorp 12 на [странице GitHub Releases](https://github.com/Floorp-Projects/Floorp/releases).

Обратите внимание: хотя старые версии Floorp можно скачать и установить отсюда, поддержка для них не предоставляется.

## Что такое Floorp Daylight?

В настоящее время Floorp Daylight — это название отладочной сборки для разработчиков. Если вы хотите внести вклад в разработку Floorp Browser, обратитесь к [`CONTRIBUTING.md`](https://github.com/Floorp-Projects/Floorp/blob/main/.github/CONTRIBUTING.md) в официальном репозитории.

Ранее Floorp Daylight было названием публичной бета-сборки. Теперь в стабильной версии Floorp появилась система постепенного развёртывания экспериментальных функций ([Floorp Flasco](/docs/features/glossary/#floorp-flasco)). Она позволяет пробовать новые функции без установки отдельного браузера.

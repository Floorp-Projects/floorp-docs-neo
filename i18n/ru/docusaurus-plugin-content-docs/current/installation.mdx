## Windows

### Поддерживаемые операционные системы

- Windows 11, 64-разрядная
- Windows 10, 64-разрядная

### Системные требования

- Процессор с поддержкой SSE4.1
- 2 ГБ оперативной памяти
- 200 МБ свободного места

### Установка

- **Установщик и портативная версия**

  1. Перейдите на [официальный сайт](https://floorp.app/download) и скачайте установщик для Windows или портативную версию.
  2. Портативную версию можно использовать сразу. Для установщика следуйте инструкциям на экране.

:::tip[Различия]

- **Онлайн-установщик** устанавливает Floorp из интернета.
- **Офлайн-установщик** устанавливает Floorp без подключения к интернету.
- **Портативная версия** не требует установки, но может иметь некоторые ограничения.

:::

- **Winget**

  ```shell
  winget install Ablaze.Floorp
  ```
  Предоставлено **[@Hibi_10000](https://github.com/Hibi-10000)**.
- **Scoop**

  ```shell
  scoop bucket add extras
  scoop install extras/floorp
  ```

  Предоставлено **[@SegoCode](https://github.com/SegoCode)**.

## Mac

### Поддерживаемые операционные системы
macOS Catalina 10.15 - macOS Sequoia 15

### Системные требования

- Mac с процессором Intel x86 или Apple Silicon
- 512 МБ оперативной памяти
- 200 МБ свободного места

### Установка

1. Откройте [официальный сайт](https://floorp.app/download) и скачайте `floorp-macOS-universal.dmg`.
2. Откройте загруженный файл и перетащите `Floorp.app` в папку `Applications`.

  Убедившись, что Floorp появился в папке «Программы» или в Launchpad, вы можете извлечь установщик Floorp.

## GNU/Linux

### Требования к программному обеспечению

- **Для работы Floorp требуются следующие пакеты**:

    - GTK+ 3.14 или выше
    - X.org 1.0 или выше (рекомендуется 1.7 или выше)
    - libstdc++ 4.8.1 или выше
    - glibc 2.17 или выше

- **Для наилучшей работы убедитесь, что установлены следующие пакеты:**

    - NetworkManager 0.7 или выше
    - DBus 1.0 или выше
    - GNOME 2.16 или выше
    - PulseAudio

### Установка

Поддерживаемые менеджеры пакетов:
```text
1. PPA (Ubuntu, Linux Mint и др.)              "https://ppa.floorp.app"

2. Flatpak (все дистрибутивы Linux)            "https://flathub.org/apps/one.ablaze.floorp"

3. tarball (все дистрибутивы Linux)            "https://GitHub.com/Floorp-Projects/Floorp/releases/latest"

4. AUR bin (дистрибутивы на базе Arch)         "https://aur.archlinux.org/packages/floorp-bin/" **Неофициально**

5. AUR (дистрибутивы на базе Arch)             "https://aur.archlinux.org/packages/floorp/" **Неофициально**

6. SBo bin (дистрибутивы на базе Slackware)    "https://slackbuilds.org/repository/15.0/network/floorp-bin/" **Неофициально**
```

Версия Flatpak может иметь свои ограничения из-за «песочницы». [Подробнее](/docs/issue-tracker/flatpak)

## Загрузка с GitHub Releases

Скачать релизы Floorp 12 можно на [странице релизов GitHub](https://github.com/Floorp-Projects/Floorp/releases).

Обратите внимание: хотя отсюда можно скачать и установить более старые версии Floorp, поддержка для них не предоставляется.

## Что такое Floorp Daylight?

Сейчас Floorp Daylight — это название отладочной сборки для разработчиков. Если вы хотите участвовать в разработке Floorp Browser, обратитесь к [`CONTRIBUTING.md`](https://github.com/Floorp-Projects/Floorp/blob/main/.github/CONTRIBUTING.md) в официальном репозитории.

Раньше Floorp Daylight был названием публичной бета-сборки. Сейчас в стабильной версии Floorp действует система постепенного развёртывания экспериментальных функций ([Floorp Flasco](https://docs.floorp.app/docs/features/glossary/#floorp-flasco)). Она позволяет пробовать новые функции без установки отдельного браузера.

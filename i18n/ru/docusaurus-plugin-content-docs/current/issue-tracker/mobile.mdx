### iOS
Floorp для iOS создаётся на основе [Firefox для iOS](https://github.com/mozilla-mobile/firefox-ios). Исходный код: [Floorp-Projects/floorp-ios](https://github.com/Floorp-Projects/floorp-ios).

### Android
Версия для Android пока не планируется. Наши ресурсы ограничены, а каждая дополнительная платформа значительно увеличивает расходы на сопровождение.

:::caution
Портативную версию Floorp нельзя назначить браузером по умолчанию в Windows.
:::

Портативная версия Floorp намеренно сделана так, чтобы её нельзя было назначить браузером по умолчанию.

### Почему её нельзя назначить по умолчанию?
В Windows браузеры обычно регистрируются через установщик, что позволяет назначать их браузером по умолчанию. Поскольку портативная версия Floorp не содержит установщика, у неё нет необходимой регистрации для выбора в качестве браузера по умолчанию.

### Альтернативные решения
Мы не поддерживаем эту возможность, но вы можете использовать стороннее программное обеспечение, которое регистрирует портативные версии программ как используемые по умолчанию. Используйте такое ПО на свой страх и риск.

Кроме того, существует [обходной путь](/docs/other/floorp-portable-default-browser/) с использованием скрипта .bat.

Подробности см. в связанной проблеме.

**Windows изначально не поддерживает назначение Floorp Portable браузером по умолчанию, но есть обходной путь с использованием скрипта .bat.**

Этот метод заключается в создании пакетного файла (.bat), содержащего всё необходимое для регистрации Floorp Portable в качестве обработчика веб-браузера по умолчанию.

После загрузки пакетного файла поместите его в тот же каталог, где находится floorp.exe (каталог портативной версии Floorp), и запустите его.

[Скачать .bat](https://gist.github.com/regularentropy/8a61e32d444e7016ed1839f73981fd8d)

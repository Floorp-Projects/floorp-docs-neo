## Куда отправлять сообщение о проблеме

### Проблемы версии для компьютеров

Сообщить о проблеме можно следующими способами:

- [Открыть проблему на GitHub](https://github.com/Floorp-Projects/Floorp/issues)
- Отправить сообщение в канал `#en-bugs` в [официальном Discord](https://discord.floorp.app) с тегом «Desktop»

### Проблемы версии для iOS

- [Открыть проблему на GitHub](https://github.com/Floorp-Projects/floorp-ios/issues)
- Отправить сообщение в канал `#en-bugs` в [официальном Discord](https://discord.floorp.app) с тегом «iOS»

Если вы не уверены, является ли ваша ситуация проблемой Floorp, спрашивайте в [Discord Floorp Projects](https://discord.floorp.app) или на [Reddit (r/Floorp)](https://reddit.com/r/floorp)!

:::note

Вопросы сообществу предназначены для проверки, а не для официальной отправки сообщений о проблемах. Пожалуйста, при публикации также ознакомьтесь с правилами сообщества.

:::

## 1. Проверьте существующие проблемы
Перед отправкой проверьте уже существующие проблемы: возможно, решение уже есть.
Дублирующиеся сообщения замедляют процесс решения.

Также обратитесь к разделу [«Трекер проблем»](/docs/issue-tracker) в этой документации.

## 2. Проверьте проблему в чистой среде
Проблема может быть вызвана вашей средой браузера. Выполните следующие шаги:
- **Обновитесь до последней версии Floorp**

  Возможно, проблема уже решена в последней версии.\
  Пожалуйста, проверьте, используете ли вы последнюю версию Floorp.

- **Отключите все расширения и дополнения браузера**

  Проблема может быть вызвана конфликтом Floorp с каким-либо дополнением.\
  Если после отключения дополнений проблема исчезла, обратитесь к разработчику дополнения или найдите альтернативу.

- **Очистите кэш и cookie браузера**

  Проблема может быть вызвана кэшем браузера.

- **Создайте новый профиль**

  «Профиль» — это механизм браузера для разделения ваших настроек, логов и т. д.\
  Проблема может быть вызвана изменениями в обработке данных внутри программы, особенно после обновления Floorp.

  [Документацию по менеджеру профилей Firefox можно найти здесь!](https://support.mozilla.org/en-US/kb/profile-manager-create-remove-switch-firefox-profiles)

## 3. Проверьте, специфична ли проблема для Floorp

- **Проверьте, возникает ли проблема в последней версии Firefox**

  Floorp основан на Firefox.
  Пожалуйста, проверьте, возникает ли проблема в Firefox.
  Если проблема возникает и в Firefox, отправьте сообщение в Mozilla — организацию, стоящую за Firefox.

  Проверять, связана ли проблема со специфичной для Floorp функцией, не нужно.

## 4. После всех проверок

Благодарим за проверку проблемы по этим рекомендациям.

Отправьте сообщение о проблеме на [GitHub Issues](https://github.com/Floorp-Projects/Floorp/issues) или в канал `#en-bugs` [официального Discord](https://discord.floorp.app).

Следующая информация поможет решить вашу проблему:

- **Подробные пошаговые инструкции**

  Опишите шаги воспроизведения проблемы.

  ```text
  Шаги:

  1. Нажмите кнопку «Настройки»
  2. Перейдите в раздел «Дизайн»
  3. Выберите дизайн Floorp Daylight Fluerial

  Результат:

  Раскладка панели вкладок ломается
  ```

- **Снимки экрана**

  Пожалуйста, приложите снимки экрана с проблемой.

- **Вывод консоли инструментов разработчика браузера**

  Так же, как инструменты разработчика открываются сочетанием `Ctrl` + `Shift` + `I` (`Cmd` + `Option` + `I` на Mac), Browser Toolbox открывается сочетанием `Ctrl` + `Alt` + `Shift` + `I` (`Cmd` + `Option` + `Shift` + `I` на Mac).\
  Этот лог консоли поможет решить проблему.

  [Документацию по Browser Toolbox в Firefox можно найти здесь](https://firefox-source-docs.mozilla.org/devtools-user/browser_toolbox/index.html)

## Сообщение об уязвимостях

:::warning

**НЕ отправляйте сообщения об уязвимостях обычным способом: уязвимости могут быть использованы.**

:::

Об уязвимостях необходимо сообщать одним из следующих способов:

- [GitHub Security](https://github.com/Floorp-Projects/Floorp/security)
- Создать тикет об уязвимости в канале `#about-support` [официального Discord](https://discord.floorp.app)
- Отправить письмо на [contact@floorp.app](mailto:contact@floorp.app)

Примечание: обычные сообщения о проблемах по почте не принимаются.
